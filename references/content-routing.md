# 内容类型路由

## video

- 获取页面文案和媒体元数据。
- 优先字幕，缺失时执行带时间戳 ASR。
- 结合语义转折、视觉触发词和场景变化建立章节。
- 静态状态保存截图，动态过程保存短片。

## gallery

- 保留作者正文和图片原始顺序。
- 分离页面文字与图片内文字。
- 对图片执行 OCR 和视觉理解，避免只提取 OCR 而忽略图表、布局或前后关系。
- 输出引用使用“图片 1、图片 2”，不虚构视频时间戳。
- 没有音视频时不创建 `transcript.md`，不声明 `transcript_file`、转写方式、时间点或短片字段。

## long_text

- 只提取作者正文及其标题、作者和发布时间。
- 排除评论、推荐、导航、热榜和广告。
- 没有配图时跳过视觉路由。
- 保留段落结构，再提炼核心观点、步骤、例子和限制。

## mixed

- 在抖音 `/note/` 路由中，`mixed` 表示“作者正文 + 原序图片”的非视频内容。带音频或视频轨的来源进入 `video` 工作流。
- 不把图中文字重复算作作者正文。
- 每个结论注明来自作者正文、图片 OCR、画面直接事实还是视觉/Agent 推断。

## 非视频溯源分层

- `source-content.md` 只保留标题、作者、发布时间和作者直接正文。
- `image-analysis.md` 是派生层，对每张图片分开记录 OCR、直接可见事实和带置信度的视觉推断。
- `summary.md` 是 Agent/自动摘要层。`mcu analyze` 产生的是准备稿，必须对照前两层和原图校订后再 `mcu finalize`。
- 外部图片路由与视频流程共用 `vision.max_visual_calls`；上传同时受 `vision.max_upload_mb` 和 provider 单图限制。无可用 provider 时保留分层占位稿，明确交由宿主 Agent 校订。

## 输出降级

获取部分内容时可以生成 `partial` 包，但必须列出缺失部分。视觉是核心内容而视觉链全部失败时使用 `failed_visual`，不得把只基于字幕的结果描述为完整理解。
